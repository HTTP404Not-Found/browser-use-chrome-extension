Browser Use — Settings

Configure your AI provider. Any OpenAI-compatible endpoint works (OpenAI, DeepSeek, OpenRouter, vLLM, Ollama, etc.).

Tips

  • For tool calling (the Agent tab), pick a model that supports function calling (e.g. gpt-4o-mini, deepseek-chat, qwen-plus).
  • For DeepSeek, set base URL to https://api.deepseek.com/v1 and model to deepseek-chat.
  • For OpenRouter, use https://openrouter.ai/api/v1 and your model slug.
  • For a local Ollama model, use http://localhost:11434/v1 with any tool-capable model.
  • Restart the side panel after saving for changes to apply.
